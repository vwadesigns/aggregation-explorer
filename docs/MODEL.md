# Model and implementation specification

Version: `dda-explorer-0.1.0`. Prepared for the October 5, 2026 project discussion.

## Source-derived core

Source: Siteur et al. (2023), PNAS 120(2), e2202683120.

- https://doi.org/10.1073/pnas.2202683120
- https://github.com/liuqx315/PS-Resilience-in-Ecosystems
- Inspected notebook: `Figure3/DDA Model_LS.ipynb`, blob `6cbecf45691c514a32a8db5fc553316fa1aa6c49`.

The implemented equations are:

```
R(u,v) = u*v - a*u/(b+u)
du/dt =  R(u,v) + Da * Laplacian(u)
dv/dt = -R(u,v) + Db * Laplacian(v)
```

The reviewed DDA research preset uses a=4, b=1, T=4, Da=1/16, Db=1. These five coefficients are retained in the app's default preset. Research resolution, domain size, recording times, unseeded random initialization, in-place GPU updates, plotting, and data storage are not copied as a purported exact reproduction.

The model's continuous u+v integral is conserved with appropriate no-flux/periodic boundaries. The number and area of thresholded patches are not the conserved quantity. The app reports the actual float32 mean budget and relative numerical drift, without renormalizing it after each step.

## Explicit adaptations

### Initial geometry

Seeded patches are generated by a xorshift32 stream from the chosen integer seed. Centers are random within the explicitly defined model domain. Radii follow a bounded log distribution around `radius`; random ellipse stretch and 3-/5-fold radial perturbations provide irregular outlines. Some patches receive a secondary overlapping lobe. A resolved smooth transition creates a continuous initial field. No noise is injected after initialization.

For a requested approximate initial geometry coverage c, the number of initial stamps is estimated as:

```
round(-log(1-c) * Lx*Ly / (pi * radius^2 * (1 + 0.6*variation^2)))
```

The union and later display threshold mean actual black area will differ. This estimate is an authored initialization rule, not a Siteur equation.

Let g be the resulting continuous union in [0,1]. Set mobile mean v0=min(0.65,0.3*T), retained floor=0.025, and:

```
u = floor + (T-v0-floor) * g / mean(g)
v = v0
```

This fixes the mean combined starting budget across seeds to float32 precision without continually enforcing a particular black area.

### Reference perturbations

The positive uniform DDA root is derived as:

```
u0 = (T-b + sqrt((T-b)^2 - 4*(a-T*b))) / 2
v0 = T-u0
```

Non-real/non-positive equilibria are rejected. Seeded, mean-centered small noise is added to u and subtracted from v. This paired initialization keeps the total fixed; it is not the notebook's independently randomized A and B. It is included as an equation-reference experiment, not a claim to reproduce the published initial realization.

### Numerical update

Fields are interleaved float32 pairs `(u,v)` at cell centers. CPU arithmetic uses JavaScript number intermediates and float32 storage. WGSL uses float32 operations. Both use separate old/new arrays, the same four-neighbor finite-difference stencil, and explicit Euler stepping:

```
lap(q) = (left - 2*q + right)/hx^2 + (up - 2*q + down)/hy^2
```

Closed boundaries omit material flux across exterior cell faces, implemented by substituting the edge cell for its missing neighbor. Periodic boundaries wrap the neighboring index. These policies apply to both fields.

A conservative initial bound chooses dt from 0.02 / 2^k:

```
Dmax = max(Da, Db)
reactionBound = max(32, 1.6*initialMaxU, a/b)
safe = 0.72 / (2*Dmax*(1/hx^2 + 1/hy^2) + reactionBound)
```

Select the largest dyadic step no larger than both 0.02 and `safe`. Fine mode halves it again. This heuristic incorporates starting reaction scales; it is not a proof of stability for every possible evolved field. The run checks finite values, nonnegativity and budget drift. Negative values are reported, not silently clipped. A relative budget drift above 1% stops the run; above 0.2% displays a warning. No automatic renormalization changes the equations.

The browser GPU batches dispatches with alternating bind groups. All neighbor reads in one update refer to its old state. No workgroup is expected to synchronize with other groups inside a dispatch. Source references used for the browser interface include the W3C WGSL specification and WebGPU buffer-mapping documentation:

- https://www.w3.org/TR/WGSL/
- https://developer.mozilla.org/en-US/docs/Web/API/GPUBuffer/mapAsync

### Grid and coordinates

```
nx = resolution
ny = round(nx/aspect)
Lx = length
hx = hy = length/nx
Ly = ny*hy
x_i = (i+0.5)*hx, y_j = (j+0.5)*hy
```

These are coordinates of this independent model domain, not reconstructed World Machine world coordinates. A future WM port must use the verified WM coordinate/binding path. No WM host script or shader is supplied in 0.1.

Different grids sample different initial fields and approximate diffusion differently. Export resolution is separate and does not change this model grid. A coarse grid can pin interfaces and distort long-time coarsening. Neither CPU tests nor a pleasing preview establish continuum convergence.

### Timeline

Model time is represented by integer step IDs multiplied by the fixed dt. Requested time is rounded to the nearest step. The slider maps 0..1000 to `expm1(position/1000 * log1p(horizon))`. The horizon starts at 512 and doubles to at most 65,536. It changes only the accessible time range, not the solver step or coefficients.

Checkpoints contain both float32 fields, not binary masks. A canonical checkpoint is stored every four model-time units. Age zero is pinned. A least-recently-used cache retains at most 96 states and approximately 48 MiB. On a backward seek, restore the latest retained state no later than the target, then replay forward. Evicting a checkpoint changes speed, not the intended solution. No crossfade or backward numerical integration is used.

Controls are handled by one serialized worker pump. New seeks supersede old intent. New configurations invalidate the old history and suppress stale messages. Export snapshots capture the selected recipe, fields, and mask settings, so a subsequent parameter change does not relabel old pixels with a new seed.

### Display and measurements

Black patch when u >= threshold; white otherwise. Inversion is optional. For display/export, bilinear sample u and then apply the fixed threshold. The threshold never feeds back into the PDE. The default threshold is 3. No per-frame min/max stretch is applied.

Patch count and occupied area are measured on the simulation grid with four-neighbor connectivity; periodic mode connects across the domain boundaries. These measurements can differ from components in a resampled/exported raster. Pinning a stage stores an age bookmark, not an extra copy of all history.

## Out of scope

No SDF mode; no exact Texel animation reconstruction; no explicit grass field; no wind vector, sand height, drainage, terrain erosion, directional transport, or post-simulation shape inflation; no native WM plug-in; no automatic cloud service; no promise that independent tiles form one seamless simulation; no validated cross-backend bit identity.
